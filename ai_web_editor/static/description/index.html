AI Web Editor Assistant — an AI design partner inside Odoo's website editor

Adds a floating ✨ AI Assist panel to Odoo's visual website editor. Describe a section in plain language and it appears on the page — or highlight text, say "rewrite professionally", and the section is rewritten in place.

Features

  • Create: "a hero with dark gradient, headline 'Grow Faster', email signup button" → a ready-to-tune Bootstrap section inserted after your selection.
  • Rewrite: highlight text + "rewrite this professionally" → the containing section is replaced in place, with your highlighted text as the rewrite target.
  • Native workflow: results land directly in the editor DOM — adjust with Odoo's own tools, undo, save as usual. The AI never writes to the database behind your back.
  • Odoo-aware output: generated sections use Bootstrap 4.6 utilities and Odoo's editable text patterns.
  • Sanitized server-side: scripts, iframes, event handlers and javascript: URIs are stripped before anything reaches the editor.
  • Group-gated: only users in "AI Web Editor / Designer" can generate.

Works with

Anthropic, OpenAI, OpenRouter or local Ollama — shares the LLM configuration system (ai_digest module) or works standalone via System Parameters.

Works with Odoo 16 Community and Enterprise.
