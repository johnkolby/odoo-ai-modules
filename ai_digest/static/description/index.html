AI Business Digest — permission-aware AI summaries of your Odoo data

Get an executive summary of your operations — receivables, payables, sales, CRM pipeline and your overdue activities — written by an LLM, scoped to exactly what the requesting user is allowed to see.

Features

  • Interactive wizard (Settings → AI Digest): pick a date range, get a structured summary — the exact JSON sent to the LLM is shown for transparency.
  • Collaborative Discuss bot: ask follow-ups in a channel (?ai dig into payables) and get deep dives — aging buckets, customer concentration, stale leads, payment history.
  • Daily digest: cron posts an org-wide summary into any private Discuss channel.
  • Role-aware answers: summaries are framed for the asker (finance, sales, admin).
  • Permission-safe by design: data is collected as the requesting user (no sudo), record rules and multi-company rules apply automatically; only aggregates leave the database.

LLM providers

Anthropic, OpenAI, OpenRouter or a local Ollama — configured via System Parameters. One setting to switch models; nothing is hardcoded.

Configuration

After install, set ai_digest.provider, ai_digest.api_key (and optionally ai_digest.model, ai_digest.channel_id) in Settings → Technical → System Parameters. See README.

Works with Odoo 16 Community and Enterprise.
